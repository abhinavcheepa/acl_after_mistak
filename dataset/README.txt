Place Hindi UD dataset files here:

  train.conll  — training data (~13,306 sentences)
  dev.conll    — validation data (~1,659 sentences)
  test.conll   — test data (~1,684 sentences)

Download from:
  https://github.com/UniversalDependencies/UD_Hindi-HDTB

File format (CoNLL):
  word<TAB>TAG
  (blank line between sentences)

Example:
  राम     PROPN
  घर      NOUN
  जाता    VERB
  है      AUX

  सीता    PROPN
  ...
